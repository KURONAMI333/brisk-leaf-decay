Chop a tree and the leaves left hanging in the air fall within about a second, instead of decaying one by one over several minutes.

Each orphaned leaf still falls through its own decay code, so the drops are exactly what natural decay gives: saplings, sticks and apples. Modded leaves built on vanilla leaves behave the same way.

- **Only orphaned leaves** — leaves you placed yourself never decay, and a leaf reconnected to a log before it falls is kept.
- **Follows the game rule** — with `randomTickSpeed` set to 0, leaves don't decay at all, as in vanilla.
- **Server side** — install it on the server (or in singleplayer); players joining don't need it. Nothing to configure.
